<h1>Использование макетов (Layouts) и частичных представлений (Partial Views) в приложении ASP.Net</h1>

<h2>Задание</h2>
<ol>
  <li>Создать проект ASP.Net Core с реализацией паттерна MVC. Условное название приложения – <strong>"Электронная библиотека"</strong>.</li>
  <li>
    Используя работу с макетами и частичными представлениями, обеспечить следующую структуру и функциональность приложения:
    <ul>
      <li>
        <h3>Главная страница (Home Page):</h3>
        <ul>
          <li>Использует главный макет, содержащий общую структуру сайта (навигационное меню, футер и т.п.).</li>
          <li>Отображает популярные и новые книги.</li>
        </ul>
      </li>
      <li>
        <h3>Страница Каталога (Catalog Page):</h3>
        <ul>
          <li>Использует главный макет.</li>
          <li>Отображает все доступные книги по категориям.</li>
        </ul>
      </li>
      <li>
        <h3>Страница Деталей книги (Book Details Page):</h3>
        <ul>
          <li>Использует главный макет.</li>
          <li>Отображает подробную информацию об избранной книге, такой как обложка, название, автор, описание и т.д.</li>
          <li>Использует частичное представление для отображения подробной информации о книгах.</li>
        </ul>
      </li>
    </ul>
  </li>
</ol>
